# Молекулярні докази таксономічного відновлення *Stenurella sennii* nom. res. у філогеографічній структурі *S. melanura* (v2.0)

Оновлена інтерактивна наукова вебпрезентація з 60fps GPU-анімаціями, ефектом розгортання/згортання вертикального променя при зміні слайдів та повним заповненням візуальних блоків.

## Оновлення версії 2.0
- **60 FPS оптимізація:** переведення анімацій паралаксу, лічильників (`requestAnimationFrame` без проміжних ре-рендерів React) та шторки переходів на апаратне прискорення (`transform: scale3d / translate3d`, `will-change`).
- **Ефект телевізійного променя (TV Shutter):** при переході між слайдами центральна вертикальна лінія миттєво розгортається на всю ширину екрана (`scaleX`), змінює слайд і симетрично згортається назад у промінь.
- **Заповнення композиції слайдів:** додано схему таксономічної колізії на слайд 2, тріаду інтегративної таксономії на слайд 3, графік термоциклування ПЛР (`HCO/LCO`) на слайд 4, інтерактивне ML-філогенетичне дерево (`PhyML 3.0`) на слайд 5 та шкалу порівняння генетичних дистанцій і морфометричну схему ваучерів `PSFOR1138-17` vs `Sm1` на слайд 6.
